<h1 align="left">📆🤖 AGENTE DE AGENDAMENTOS</h1>


<h2 align="left">❓O QUE É O PROJETO?</h2>


<h3 align="left">Este projeto consiste em um agente automatizado que realiza o agendamento de eventos de forma automática utilizando a plataforma n8n e integração com o Google Calendar.<br>Basta informar o nome do evento, a data e o horário, e o sistema se encarrega de criar o evento automaticamente na agenda.</h3>

###

<h2 align="left">⚙️ COMO FUNCIONA?</h2>

###

<h3 align="left">O funcionamento é simples e direto:<br><br>📩 O usuário envia as informações do evento<br>🌐 A requisição é enviada para o webhook<br>🔔 O webhook é acionado automaticamente<br>⚙️ O n8n processa os dados e cria o evento no Google Calendar<br>📊 As informações também são registradas no Google Sheets</h3>

###

<h2 align="left">✉️ O QUE O USUÁRIO PRECISA INFORMAR?</h2>

###

<h3 align="left">Para que o evento seja criado corretamente, é necessário fornecer:<br><br>-Nome do evento;<br>-Data;<br>-Horário.</h3>

###

<h2 align="left">🤖 O QUE O SISTEMA FAZ?</h2>

###

<h3 align="left">Após receber as informações, o sistema:<br><br>-Organiza os dados do evento;<br>-Integra com o Google Calendar;<br>-Cria o evento automaticamente na agenda;<br>-Registra os dados em uma planilha.</h3>

###

<h2 align="left">📊 OS DADOS SÃO ARMAZENADOS?</h2>

###

<h3 align="left">✅ Sim.<br><br>As informações são registradas automaticamente no Google Sheets, incluindo:<br><br>-Usuário;<br>-Evento;<br>-Data;<br>-Hora.<br><br>Isso permite controle, organização e acompanhamento dos agendamentos realizados.</h3>

###

<h2 align="left">🚧 O QUE ESTÁ EM DESENVOLVIMENTO?</h2>

###

<h3 align="left">O projeto ainda está em evolução e futuramente contará com funcionalidades como:<br><br>-Integração com WhatsApp e Instagram;<br>-Edição e cancelamento de eventos;<br>-Consulta de eventos futuros e passados;<br>-Adição de descrições nos eventos;<br>-Sugestões inteligentes de horários.<br><br>Além disso, o sistema poderá:<br><br>-Consultar planilhas (Excel/Sheets);<br>-Exibir catálogos de produtos;<br>-Informar preços e descontos automaticamente.</h3>

###

<h2 align="left">🎯 OBJETIVO DO PROJETO</h2>

###

<h3 align="left">O objetivo principal é:<br><br>-Automatizar o agendamento de compromissos;<br>-Reduzir tarefas manuais;<br>-Tornar o processo mais rápido e eficiente;<br>-Evoluir para um assistente completo de gestão de eventos.</h3>
